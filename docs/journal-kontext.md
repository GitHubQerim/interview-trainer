# Journal-Kontext – Interview-Trainer

## Kurs
`DLBSEPPSD01_D` – Projekt: Software Development. Prüfungsleistung: Projektpräsentation (Bongo), 15 Minuten.

## Gewählte Aufgabenstellung (Kurzfassung, paraphrasiert – Original-PDF nicht ins Repo legen)
Aufgabenstellung 2: Entwicklung einer Webanwendung inkl. Backend. Vorher: Problem, Nutzer:innen und Nutzen identifizieren und begründen, warum eine Webanwendung die richtige Lösungsform ist – dieses Konzept war dem/der Tutor:in zur Freigabe vorzulegen (erledigt: Modulbetreuung, 16.09.2026, siehe `journal.md`).

## Mindestanforderungen (Checkliste)
- [ ] Problem/Nutzer:innen/Nutzen dokumentiert und begründet (Web statt andere Anwendungsform)
- [ ] Schriftliches Konzept: Komponenten + Beziehungen der Webanwendung
- [ ] Wireframes der Oberflächen
- [ ] Softwarearchitektur in Architektur-Notation (UML oder C4 Model), inkl. Backend in Gesamtarchitektur
- [ ] Vorgehensmodell gewählt und begründet (z.B. Scrum)
- [ ] Webanwendung ist SPA
- [ ] Modernes Web-Framework genutzt (React)
- [ ] Kernfunktionalitäten durch Unit-/Integrationstests abgedeckt
- [ ] Code dokumentiert
- [ ] Backend dokumentiert und getestet
- [ ] Implementierung an Code-Auszügen im Detail erläutert (Navigation, Dateneingabe/-verarbeitung, Datenstrukturen)
- [ ] Kritische Evaluation: Zielerreichung, Verbesserungspotenzial, Lessons Learned, persönliche Entwicklung, positiv/negativ Erlebtes
- [ ] Personenbezogene/unternehmensbezogene Daten anonymisiert
- [ ] Vollständiger Code auf GitHub veröffentlicht, Link auf Titelfolie
